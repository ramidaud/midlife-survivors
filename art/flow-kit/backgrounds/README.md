# Flow background plates

Ten empty rooms, each delivered as a day and night PNG at 1920×1080. Open [review.html](review.html) for the pairs or [the contact sheet](contact-sheet-backgrounds.png) for the whole set. Filenames match the background table in the brief.

Use these as Flow scene references. The open foreground and middle floor leave room for character performances. The camera and major furniture positions match within each day/night pair. These are separate plates, not pixel-registered lighting layers.

Built-in imagegen created the day compositions from the original office key art, then edited each day source for night lighting. The final exports use the style guide's 14 environment colors on a 640×360 logical grid enlarged 3× with nearest-neighbor sampling. Files are opaque RGB PNGs. No magenta key is needed.

The Executive Wing's founder frame is an abstract geometric tribute. This keeps the brief's no-characters rule. All notes, posters and banners use shapes without lettering. No cast, enemies, creatures, logos or UI appear.

- [Manifest](manifest-backgrounds.json) lists all twenty plates and the palette.
- [Generation prompts](generation-prompts.json) preserves the final prompt set and reference roles.
- [Validation](validation-backgrounds.json) records dimensions, palette, opacity, repeated 3× pixels, file sizes and day/night luminance checks. All twenty plates were visually inspected.

This delivery covers backgrounds only. The clean character portraits are the next set after Rami's review. No runtime files or game version changed.
