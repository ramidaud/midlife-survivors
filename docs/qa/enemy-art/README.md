# Batch 1 combat art QA: V. 1.28.12 (Codex)

Browser checks use Phaser 3.80.1 in the local HTTP game, at 1280x800 and 390x844. Direct file:// opening could not be exercised because the browser tool permits only HTTP(S). Evidence is saved alongside this file. These measurements describe this computer/browser; they are not a guarantee for every phone.

- Normal Tax Bracket 0 run: age 40 to 45.0035, 225.16 seconds of active play, 109 peak active enemies, 4 HP remaining. Automated movement and normal first-choice level-ups, no health/speed/weapon/difficulty edits or age skipping. Sampled rolling performance window: 99.98 FPS average, 92.79 minimum. No captured errors or leaderboard requests. `age-45.json` and desktop proof record the result.
- Stress fixture: 350 enemies covering all ten species for six seconds, with live AI, animation and projectile logic. Physics stepping was paused to hold the crowd in view; this is a render/AI stress check, not a full collision benchmark. 99.23 FPS sampled average, 98.60 minimum. All four Bill frames observed; 315 active looping animated sprites at capture (including pings). Twinge and ghost frames are selected from state instead of free-running animations.
- Body preservation: all ten types retain the same original texture key, body width/height and offset after artwork attachment. Ping remains 14x14. No gameplay data files or leaderboard code changed.
- States: phone ring uses frames 2/3; dash returns to walk frames 0/1. Sampled Twinge phases 100/400/600/900ms map to frames 1/2/3/0. Ghost damage remains ignored by existing game logic, with its physics body still enabled. Ghost and ping receive no contact shadow.
- Fallback: disabling the comparison flag reveals all 350 originals and hides attached art. A deliberately missing phone sheet leaves Spam Likely on its original texture while the other nine types load. The missing test intentionally generates one image 404; it raises no game exception.
- Lifecycle: clearing enemies and pings removes all attached visuals and shadows. Scene restart retains the normal starting age/HP with no errors. Animations stop when the run clock stops.
- Phone: native-scale full cast is readable beside the player, no horizontal overflow, and browser logs contain no errors. A 25.4-second normal-play smoke check at 390x844 reached age 40.565 with 17 active enemies, 12 HP, about 100 FPS, no captured errors and no leaderboard requests (`phone-smoke.json`). Desktop proof includes the complete cast as well.
