# Gemini brief: Spotlight card copy (Nov 3, 2026)

Rami approved **Spotlight cards**: at big moments the screen dims, a slanted band sweeps in, a big sprite rises from the bottom left, and the character says one line in a speech bubble, with a small tip strip underneath. Each card is on screen for about 6 seconds, mid-action, so every word has to earn its place.

## Each card has
- **Kicker** (Silkscreen caps, 2-3 words): BOSS INCOMING, NEW HIRE, PROMOTED...
- **Name** (Silkscreen caps, max 20 characters): PERFORMANCE REVIEW
- **Line** (max 60 characters, spoken by the character in the sprite)
- **Tip** (max 55 characters, plain and useful)

## Write these (2 options each, so Rami can pick)
1. **Bosses** (they speak):
   - Performance Review, arrives at 45. Charges in a straight line after a clipboard flash.
   - 30-Year Mortgage, arrives at 52. Sends out shockwaves.
   - Midlife Crisis V8, arrives at 60. A sports car that does skid laps and leaves skid marks.
2. **New hires**, when a hero unlocks (the hero speaks):
   - The 9-to-5er (coffee, glasses, reliable)
   - The Soccer Dad (group chat, orange slices, sideline energy)
   - The Grad Student (deadlines, notebooks, unpaid)
3. **Rooms opening**, at promotions (a coworker speaks; name them like "Dave from IT"):
   - Break Room, Conference Rooms, Executive Wing, Wellness Corner, Server Room, Parking Lot
4. **Key tips**, the first time something happens (a hero speaks):
   - First elite (red glow, hits harder, drops loot)
   - First boss chest (BONUS APPROVED)
   - First evolution
   - Low health

## Rules
- Warm, recognizable midlife humor. Never mean, no brand names, no em dashes.
- Use the existing cast's voice from your earlier passes (`docs/handoffs/gemini-captions.md`, `gemini-writing-2.md`).
- Return a Markdown table per section, plus a short change-log block for `docs/handoffs/gemini-changes.md`.
