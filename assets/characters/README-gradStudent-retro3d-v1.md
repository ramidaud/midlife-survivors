# gradStudent retro rendered skin v1

Art-only local review draft, generated using the normal v2 sheet for identity and the retro 9-to-5er for finish. `The Grad Student at 45`. No runtime or version changes.

- Native PNG: `gradStudent-retro3d-walk-56x60-v1.png`, 448x300, 8 columns x 5 rows of 56x60 cells.
- Rows: DOWN, UP, LEFT, RIGHT, IDLE. Idle 0-3 breathe/blink, 4-7 check notebook.
- Sole line y54, matching the normal v2 identity reference. Uniform scale across all 40 poses; no stretching to fit cells.
- Five 3x GIF previews target 75 ms. GIF centisecond rounding can encode 70 ms; use 75 ms in game. Full sheet check at 2x.
- Exact opaque #FF00FF background. Game palette plus the same six shades as the 9-to-5er: #26304A, #697789, #B5956C, #D87849, #F7E4BB, #6A463A.

Faceted low-poly shading, plastic highlights and left rim light are intentional cosmetic differences. Darker material edges replace the regular continuous navy outline. Native palette mapping prevents soft magenta halos. Notebook, mug, backpack and glasses retained; blink frame glasses were restored from the neighboring idle pose.
