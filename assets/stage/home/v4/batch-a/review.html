Batch A · painted forest kit

Eight containing wall plates, six fall trees, three pines and eight shrub/hedge modules. Every production image is RGBA with hard alpha. No files from the rejected v3/boundary kit are used. This is art review only, with no game changes.

Rami approved the autumn gold #D8AD4A. The approved red maple stays pixel-identical. Source-size normalization follows the approved Step 0 process: retain original imagegen rasters, fit/crop proportionally to an exact 8× working raster, then exact 8×8 block mode and material-family palette mapping. Painted core patches and one-pixel join repairs are documented.
